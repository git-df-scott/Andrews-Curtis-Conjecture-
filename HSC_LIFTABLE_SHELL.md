# Height 16–23: one capped positive-certificate attempt

Fourth strike. This is not a complete shell or a full-orbit separation
certificate. No global height upper bound is asserted.

## Exact domain before search

The inherited Theorems 2–4 in HSC_MIXED_BLOCK_NORMAL_FORM.md apply to H<=23
on states reachable from AK(3) or standard. Every coordinate is nonidentity
and has length <=22; its short representative is the unique geodesic.
The annular corollary turns every staying H_SC conjugation into free
conjugacy. Multiplication lifts literally. Hence a positive connecting path
in this domain would be a genuine F2 AC trivialization.

Vertices here are unordered pairs of signed free cyclic classes. Every
normalized multiplication is generated by retaining a signed cyclic word b
and enumerating **all** reduced signed conjugates u of the other class with
|u|<=23-|b|. Both |u|+|b| and |free(ub)|+|b| must be <=23 before the output
is cyclically normalized. This includes arbitrary conjugation through the
proved edge normal form; there is no heuristic conjugator cutoff.

The new acsearch/hsc_seam.py applies this inherited domain through 23 while
preserving the old height-15 implementation byte-for-byte. It generates
conjugates by inside-out wrapping. The independent verifier uses explicit
reduced conjugator words and rejects boundary cancellation before sorting.
The two routes agree on the complete capped transcript.

## Fixed query and hard stops

Preflight is frozen in experiments/fourth_strike/preflight.md. The query
was chosen once at H=23, with a cap of 2,000,000 candidate multiplication
events and 20,000 discovered fibers. A state or event cap is an incomplete
traversal, not a completeness bound for AC orbits.

Start: the AK(3) signed cyclic fiber. Targets: any fiber in the already
certified standard height-15 component. The frozen graph is loaded, not
recomputed. Its eight free-generator symmetries are used only for membership
in that standard component. AK(3) discovery states are not identified under
those symmetries. A target hit would have stopped the attempt for literal
path extraction and independent F2 verification.

## Bounded two-M observations from the same transcript

Discovery depths in M moves are 1, 504, 2,187, 1,371 vertices at depths
0,1,2,3 respectively. The tree contains 3,558 consecutive two-M segments:
3,378 keep the same changed coordinate lineage and 180 switch it. Independent
checking verifies the switched-target bound rho<=2L on every such segment.
These are discovery-tree data, not a census of minimal mixed blocks.

The same-target witness with indices 0,70,1355 has canonical seams

    (YYYYxxx, YXYxyx)                    width 13
    (YYYxyyXYXyxYXYxxx, YXYxyx)           width 23
    (YYYxyyXYx, YXYxyx)                  width 15.

Its full two-M path peaks at 23. A frozen two-M replacement reaches the same
endpoint through height 15. The complete normalized root neighborhood at
height 23 excludes that target, so two is the minimum M count in this
sublevel. This disproves deducing a low seam from M-minimality alone; it
does not refute height-first minimality. Both literal ledgers are stored in
astra_fourth_strike.json and independently replayed.

## Entry/exit scope correction

The 24 normalized height-16 exits inherited from Strike #3 describe exits
whose landing height is exactly 16. They are not a compulsory gateway to
all higher paths. A frozen 24-step AK(3) prefix stays <=15 until the last
multiplication, which jumps 15->24. Another literal macro conjugation with
g=y^6 jumps directly 13->25. All displayed coordinate words have length
<=30, so these heights are exact H_SC geodesic heights.

These paths are not asserted minimal. They show that an entry-at-16
restriction needs an additional normalization theorem; it cannot be read
off the old boundary certificate. Arbitrary-conjugation exits also remain
infinite in number, as already proved in Strike #3.

## Certificate meaning and reproduction

certificates/hsc_height23_attempt.json.gz is a deterministic compressed
discovery transcript, including parents and actual multiplication witnesses.
It is not an adjacency/closure certificate. The independent checker verifies
all 4,062 positive discovery edges and all target-membership tests. With
--replay it independently regenerates the entire 2,000,000-event prefix,
including its accepted count, fully processed vertices and partial stop.
Exact timings and digests are in the run logs and fourth-strike manifest.

    python -m acsearch.hsc_seam
    python scripts/check_fourth_strike.py --replay

Re-running is a reproducibility control, not a request to extend this search.
No AK(3)-to-standard path was found; no global orbit conclusion follows.
